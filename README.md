# Novelty Jewellery Website

Phase 1 storefront for the novelty jewellery business. **Little Spark Jewellery** and all prices are placeholders until the final brand/pricing is chosen.

## Included
- Responsive storefront
- 8 starter products + Design Your Own
- Generated pre-launch concept imagery
- Persistent shopping bag
- Server-authoritative GBP pricing
- Stripe-hosted Checkout
- UK shipping address collection
- Placeholder £3.50 UK Standard Delivery
- Checkout success/cancel handling
- Draft shop information page

## Stripe / Vercel
Add these environment variables in Vercel, never in GitHub:
- STRIPE_SECRET_KEY
- SITE_URL

Use Stripe test mode until all products, prices, delivery details and policies are final.

## Important
The website clearly states that the current product imagery is illustrative concept photography. Replace it with real photographs when physical products are available.
